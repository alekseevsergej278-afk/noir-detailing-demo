# NOIR — интерактивный 3D-первый экран

Статический сайт для GitHub Pages. Видео заменено настоящей glTF-моделью, которую Three.js рендерит в WebGL. Остальные разделы и демонстрационная форма сохранены.

## Запуск

Откройте папку через HTTP-сервер, например `python -m http.server 8000`. Перейдите на `http://localhost:8000`. Открытие через `file://` не поддерживает загрузку модели.

Готовый `assets/js/hero-3d.js` включён в репозиторий: установка зависимостей для просмотра и GitHub Pages не нужна.

## Изменение сцены

Исходник — `assets/js/hero-3d-source.js`, стили — `assets/css/hero-3d.css`. После изменений исходника выполните `npm install`, затем `npm run build:3d`. Шрифты, модель и сборка JS находятся локально.

Доступны вращение перетаскиванием, стрелки клавиатуры, возврат ракурса клавишей Home, три цвета кузова, три ракурса и отключение движения камеры. При reduced motion автоматическое движение выключено. Сцена отрисовывается по требованию и останавливается вне экрана и в скрытой вкладке. При ошибке WebGL или загрузки появляется сообщение с повторной попыткой; услуги и запись остаются доступны.
